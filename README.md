# LMS Project (Django REST Framework)

API для LMS-системы: пользователи, курсы, уроки, платежи.

## Технологии

- Python 3.14
- Django 6.1
- Django REST Framework
- PostgreSQL
- Redis
- Pillow
- python-dotenv
- django-filter
