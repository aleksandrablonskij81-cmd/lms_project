# LMS Project (Django REST Framework)

API для LMS-системы: пользователи, курсы, уроки.

## Технологии

- Python 3.14
- Django 6.1
- Django REST Framework
- PostgreSQL
- Pillow (для картинок)

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/aleksandrablonskij81-cmd/lms_project.git
cd lms_project
---
