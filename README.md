                  # LMS Project (Django REST Framework)

API для LMS-системы: пользователи, курсы, уроки, платежи.

## Технологии

- Python 3.14
- Django 6.0
- Django REST Framework
- PostgreSQL
- Redis
- Celery
- Pillow
- python-dotenv
- django-filter
